# Screenshot Assets

Place application screenshots in this directory with the following filenames to ensure they render correctly in the main repository `README.md`:

- `home.png` - Home Screen demonstrating current streaks, weekday calendar, task progress, and today's habits.
- `dashboard.png` - General app dashboard / landing overview.
- `tasks.png` - Task management bottom sheets (creation, edit, details).
- `statistics.png` - Analytics dashboard showing the weekly bezier efficiency chart and claimed discipline badges.
- `settings.png` - Preferences panel showing theme configurations, accent color choices, language localizations, and data controls.
